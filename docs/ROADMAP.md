# XOR 实验路线

## 已建立的接口

`XorSpec : Network → Prop` 量化四个区域中的全部实数输入。`XorSpec.correct_label` 从 margin 规格推出严格分类正确。它是条件定理，当前没有声称训练得到的网络满足其前提。

TorchLean 的训练结果保留实际训练后的状态；IBP/CROWN 检查和保存 checkpoint 都使用这个状态。

## 下一个里程碑：一个具体 checkpoint 的 Lean 定理

1. 固定一次训练的参数和来源信息，记录模型、种子、步数、依赖版本。
2. 将每个有限 binary32 权重的精确数值表示为有理数；拒绝 NaN / infinity。
3. 建立该权重表示与实数网络语义的连接，并锁定参数文件的身份。
4. 对四个输入区域证明 `1/4` margin。可以复用 TorchLean 已证明的 IBP/CROWN 路径，或对 4 个 ReLU 的至多 16 种激活模式分情况证明。
5. 将具体网络的 `XorSpec` 定理纳入默认构建，检查它的公理依赖。

数值界不够紧时先区分真实反例和验证方法精度不足。若确有反例，补数据或重训；不悄悄缩小输入域、降低 margin，或把目标性质作为假设。

验收：命名具体权重的定理通过 Lean 检查，无 `sorry`、`admit` 或新增的未证明安全假设。实数定理与实际浮点推理误差的连接是独立里程碑。

## 之后：神经元消融与可解释性

尝试删除一个隐藏神经元，得到子网络 `fC`。在相同输入域上证明

```text
abs ((f(x)[1] - f(x)[0]) - (fC(x)[1] - fC(x)[0])) ≤ 1/10
```

这里比较的是**两类分数之差**，因此原网络至少 `1/4` 的 margin 能推出子网络仍分类正确。仅约束一个 logit 的变化不足以得到这个结论。

若无法建立界，保留反例或未决结果；不预设某个神经元一定可以删除。
